YouTube Kanal

Kişisel kanal analitik aracı · Personal channel analytics tool

Türkçe

YouTube Kanal, sahibinin kendi YouTube kanalının izlenme ve abone verilerini haftalık bir rapora dönüştüren kişisel bir komut satırı aracıdır. Yalnız sahibinin bilgisayarında çalışır; herkese açık bir hizmet değildir, üçüncü kişiler kullanamaz.

YouTube Data API ve YouTube Analytics API'ye yalnız okuma izniyle bağlanır; kanalda hiçbir değişiklik yapmaz, video yüklemez, yorum yazmaz.

Gizlilik politikası

English

YouTube Kanal is a personal command-line tool that turns the owner's own YouTube channel view and subscriber data into a weekly report. It runs only on the owner's computer; it is not a public service and cannot be used by third parties.

It connects to the YouTube Data API and YouTube Analytics API with read-only scopes; it makes no changes to the channel, uploads no videos and posts no comments.
